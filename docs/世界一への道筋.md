# 世界一使われる植物図鑑への道筋

書いた日：2026-10-09。作者が眠っている間に、ゴール（世界中の人が、自分の土地に合った植物を知り、育てられるようにし、飢餓を減らす）から逆算して考えたもの。
事実・推測・提案を分けて書く。採るかどうかは作者が決める。

## 1. 「世界一使われる」をどう測るか

数値の目標は置かない方がよい。理由：pranet は利用者を追跡しない（広告も計測もしない）ので、正確な利用者数は分からないし、分からなくてよい。
代わりに、外から確かめられる印を目安にする。

| 印 | 今 | 1 年後の目安 | 確かめ方 |
|---|---|---|---|
| 載っている種 | 1,198（2026-10-09） | 7,000（食用すべて） | pack.json の件数 |
| 検索で見つかる | 0 ページ | 種ごとのページが検索結果に出る | 学名で検索して pranet が上位に出るか |
| 言語 | 5（画面）、300 以上（名前） | 画面 20 言語、説明 10 言語 | i18n のファイル数 |
| 訂正の提案 | 0 | 月に数件、知らない人から | GitHub の Issues |
| 他のサイトからのリンク | 0 | 大学・NGO・自治体から | GitHub の「Used by」、検索 |
| 複製 | GitHub のみ | Zenodo、Internet Archive、他の国の有志の鏡 | docs/sources.md に記録 |

## 2. なぜ使われるか（pranet にしか無いもの）

世界一のアプリと同じ土俵（面白さ、滞在時間）では戦わない。pranet にしか無い 5 つで戦う。

1. **出典が全部ある**：Wikipedia より厳しく、論文より読みやすい。学校や NGO が「根拠として使える」。
2. **オフラインで動く**：畑、山、電波の無い村で開ける。これはどの大手アプリにも無い。
3. **自分の土地から入れる**：「州 → 国」で、知らない名前の植物を写真で見つけられる。
4. **無料で、消えない**：広告なし、アカウントなし、ライセンスで保証された複製。
5. **誰でも直せる**：出典付きなら、誰の提案でも載る。

## 3. 使われるまでの 4 段階

| 段階 | 状態 | 何が起きれば次へ進むか |
|---|---|---|
| 0 | 作者だけが知っている（今） | 200 種・5 言語・検索に載る |
| 1 | 身近な人、同じ関心の人が使う | 知らない人から最初の訂正が来る |
| 2 | 団体が使う（学校、NGO、農業普及員、種子バンク） | 団体の資料に pranet のリンクが載る |
| 3 | 地域の人が地域の種を足す | 言語と種が作者の手を離れて増える |

段階 1 と 2 の間に壁がある。個人の趣味に見えるものを、団体は使わない。壁を越える鍵は「出典」「ライセンス」「引き継ぎの手引き」の 3 つで、これはもう揃っている。あとは見せ方（README と最初の画面）。

## 4. 具体策（効く順）

### 4.1 検索に載る（費用 0、効果 大）

- **事実**：Wikipedia が世界一の百科事典になった最大の理由は、検索エンジンに強いこと。今の pranet は 1 ページ（アプリ）しか無く、種ごとの URL は `#` 以下なので検索エンジンに載らない。
- **提案**：種ごとに静的な HTML ページを自動生成する（`p/<番号>.html`）。中身は名前・学名・写真・説明の冒頭・出典・アプリへのリンク。あわせて `sitemap.xml`。生成はスクリプト 1 本。7,000 種でも 7,000 ファイル（GitHub Pages で問題ない）。
- **効く理由**：「学名 + 食用」「学名 + 栽培」で検索する人（学生、農業普及員、園芸家）が世界中にいる。学名は言語に依らない。
- **状況**：この文書を書いた後に試作する（4.1 は作者の承認なしに公開しない）。

### 4.2 共有カードが広告になる（費用 0）

- もう実装済み。カードに撮影者・ライセンス・pranet の URL が焼き込まれるので、SNS で広まるたびに出典と名前が一緒に広まる。
- 足すもの：「場所」画面に「この国の食用植物 N 種」のカード（1 枚で国ごとの入口になる）。

### 4.3 団体に渡す（費用 0、効果 大、時間がかかる）

| 相手 | なぜ pranet が役に立つか | 渡し方 |
|---|---|---|
| 農業普及員・農業高校・農学部 | 出典付きで、オフラインで、学名で引ける教材 | 「引き継ぎの手引き」と同じ調子の 1 枚の紹介文（日本語・英語） |
| 国際 NGO（食料、農村開発） | 現地語の名前が 300 言語ぶんある。電波が無くても動く | 言語を足す方法（ファイル 1 つ）を示す |
| 種子バンク、植物園 | 自分たちのデータ（CC BY）が、世界中で使われる形になる | 「あなたのデータが載っています」と出典を見せる |
| iNaturalist、Wikimedia の人たち | pranet は彼らの写真と文章を正しく帰属表示して使っている | コミュニティに知らせる（宣伝ではなく報告として） |

順番は「日本の農業高校・農学部 → 日本語圏の園芸コミュニティ → 英語圏 → スペイン語・ポルトガル語圏」。理由：作者の言葉で説明できる所から。

### 4.4 言語を増やす（費用 0、効果 中）

- 画面の文字：1 言語 1 ファイル。利用者が足せる。最初の 10 言語は作者側で用意する（スペイン語・フランス語・ポルトガル語は済み。次は中国語・ヒンディー語・インドネシア語・スワヒリ語・アラビア語）。
- 説明文：その言語の Wikipedia から取る仕組みに拡張する（今は日本語と英語）。1 言語足すごとに取得が 1 時間増える程度。
- 植物の名前：すでに 300 言語以上。

### 4.5 古い端末で動く（費用 小、効果 大）

- 目的の利用者は、古い Android と細い回線が多い。
- 済んだこと：新しい書き方の回避、写真は見たときに保存、索引は 1 種 1.4 KB。
- 残り：写真をもう一段小さく（長辺 480 → 400、品質 78 → 70）、初回の読み込みを 300 KB 以下に保つ、2G 回線での読み込み時間を測る。

### 4.6 最初の画面で「何ができるか」が分かる

- 今の最初の画面は一覧だけ。初めての人には「何の図鑑か」「オフラインで動く」「出典がある」が伝わらない。
- 提案：一覧の上に 3 行だけ置く。「出典付きの食用植物図鑑」「電波が無くても動く」「あなたの土地の植物はこちら →（場所）」。初回だけ表示し、閉じられる。

### 4.7 掲示板（2ch / 5ch）に投稿する（作者の案、2026-10-09）

- **向いている理由**：園芸・農業・植物の板には、植物に詳しい人が匿名で集まっている。宣伝ではなく「作ったので間違いを探してほしい」と頼めば、出典付きの訂正が最初に集まる場所になりうる。
- **向いていない点**：匿名なので荒れることがある。投稿は消せない。最初の反応が厳しくても、それは普通。
- **やり方**：
  1. 板を選ぶ（園芸、農林水産、Web 製作など、1 つに絞る）。板のルール（宣伝の扱い）を先に読む。
  2. 短く、何ができて何ができないかを正直に書く。URL は 1 つ。
  3. 「間違いを見つけたら教えてほしい」と頼み、GitHub の報告先を添える。
  4. 返ってきた指摘は、出典が付いているものだけ取り込む。付いていないものは「出典があれば載せる」と答える。
  5. 投稿後 1 週間は毎日見て、答えられるものに答える。
- **投稿文の案**：

> 出典付きの作物・食用植物図鑑を作っています。無料、広告なし、アカウント不要、電波が無くても動きます。
> いまは FAO の主要作物 198 種。学名は World Flora Online、分布は Kew、説明は Wikipedia、写真は作者名とライセンス付き。
> 「場所」で国を選ぶと、そこに自生・導入されている作物が出ます。毒性の記録がある種には ☠ が付きます。
> まだ荒いので、間違いや足りない所を教えてもらえると助かります。出典付きの指摘はそのまま載せます。
> https://sparky397.github.io/pranet/ （コードとデータ：github.com/sparky397/pranet）

## 5. やらないこと（世界一を目指しても）

| やらないこと | 理由 |
|---|---|
| 利用者の追跡、広告、計測 | 原則 4・7。数字が分からなくても、使われているかは訂正の提案と被リンクで分かる |
| 時間を奪う仕組み（無限スクロール、通知） | 植物は毎日更新されない。信頼を削る |
| 機械翻訳を pranet の本体に入れる | 原則 1・3。利用者がその言語の Wikipedia を育てる方が長く残る |
| アカウント | サーバーと個人情報を持たない。15.6 の形で足りる |
| 写真からの自動判定 | 誤同定で人が傷つく。設計図の決定 |

## 6. 作者が起きたら決めること

1. 4.1（種ごとの静的ページと sitemap）を公開してよいか。試作はしておく。
2. 4.3 の最初の相手を誰にするか（作者の知り合いに農業・園芸の人がいるか）。
3. 次に足す画面の言語（4.4）。
4. 200 種の版を commit して公開してよいか。

## 7. 正直な見通し

- 世界一になるかどうかは、作者と私には決められない。決めるのは、知らない誰かが自分の土地の種を足すかどうか。
- 決められるのは「足したくなる状態を作ること」で、それは上の 4.1〜4.6。どれも費用はかからない。
- 最も効くのは 4.1 と 4.3。最も早いのは 4.6。最も長く効くのは 4.4。
