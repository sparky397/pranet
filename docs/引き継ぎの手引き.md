# 引き継ぎの手引き

この文書は、作者がいなくても pranet を続けられるように書いてある。人でも AI でも、ここから始められる。

## 1. 何のための図鑑か

世界中の人が、自分のいる場所に合った植物を知り、育てられるようにする。それによって飢餓を減らすことに貢献する。
詳しくは [pranet_設計図.md](../pranet_設計図.md) の 1 章。方針に迷ったら、そこに戻る。

## 2. 守ること（変えないこと）

1. 正しい情報だけを載せる。すべての情報に出典を付ける。出典のない情報は載せない。
2. 分からないことは空欄にする。推測で埋めない。
3. AI に植物の事実を書かせない。
4. 無料で使える。寄付は、したい人だけがする。
5. ローカルで動く。
6. 誰でも確かめられる（コード、出典、お金の出入りを公開）。
7. 長く残る。消さない（設計図 16 章）。

## 3. 何がどこにあるか

| 場所 | 中身 |
|---|---|
| `pranet_設計図.md` | 設計のすべて。決めたことと理由、変更履歴 |
| `scripts/` | データを集めるスクリプト。使い方は `scripts/README.md` |
| `scripts/species_list.csv` | 取り込む種の一覧。ここに学名を足すと増える |
| `data/packs/<パック>/` | 公開するデータ。`pack.json`（版）、`index.json`（索引）、`species/<番号>.json`（詳細）、`synonyms.json`（旧い学名） |
| `data/photos/` | 縮小した写真 |
| `data/tdwg_areas.json` | 場所の一覧（TDWG の大陸・地域・地区） |
| `data/places.json` | 州 → 国 → 地区の対応表（場所画面用。`scripts/build_places.py` で生成） |
| `data/overrides/`（将来） | 利用者の訂正。出典付き |
| `app/` | 図鑑アプリ。素の HTML/CSS/JS。ビルド不要 |
| `i18n/` | 画面の文字。言語を足すときはファイルを 1 つ足す |
| `docs/` | 出典一覧、ライセンス、写真の作者一覧（自動生成）、この手引き |

## 4. やり方

### 動かして見る

プロジェクトのフォルダで：

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

ブラウザで `http://localhost:8766/app/` を開く。

### データを作り直す・種を足す

1. `scripts/species_list.csv` に学名を足す。
2. `python3 scripts/build_all.py` を実行する（初回は約 230 MB の取得と数分の処理）。
3. `scripts/validate.py` が「問題のある種 0 件」と言うことを確認する。
4. `docs/ATTRIBUTION.md` が更新されていることを確認する。

必要なもの：Python 3.12 以上、`requests`、`Pillow`、`pdftotext`（poppler-utils）。

### 公開する

GitHub の公開リポジトリに置き、GitHub Pages で配信する。版を出すたびに Zenodo と Internet Archive にも預ける。

## 5. 決まっていること・決まっていないこと

決まっていることは設計図の 2 章、決まっていないことは 13 章にある。新しく決めたら、両方と変更履歴を更新する。

## 7. 人と AI の分担

AI は植物の事実を書かない。最終判断は人がする。AI は矛盾を見つけ、検索を助け、スクリプトやアプリを書く。
AI にこの作業を頼むときは、この手引きと設計図を最初に読ませる。
